# 纹归 · 每纹一线

54 秒网页动画：六根独立丝线各自盘成蚕龙纹样，纹样随后移动与旋转归位，组成完整线稿，再依次过渡为用户提供的色稿和原布料照片。

## 时间线

- 0–24.5 秒：每纹一线，依次盘绕成形；动态线头与未盘好的自由端保持相连。
- 24.5–27 秒：独立纹样停留展示。
- 27–35 秒：纹样聚拢、旋转、归位。
- 35–37 秒：完整线稿与边框。
- 37–45 秒：色稿渐显并停留。
- 45–54 秒：过渡为真实布料照片，保留原照片比例。

原稿包含不相连的闭环。动画通过临时连接线保持每个纹样为一条连续的线，成形后连接线收隐，恢复原稿轮廓。这是艺术化的动态演绎，并非实际盘绣针法教程。

## 运行

在仓库目录运行 `python3 -m http.server 8000`，访问 http://localhost:8000 。无需安装依赖或构建。

支持暂停、重播、时间轴、速度选择、全屏和阶段跳转。尊重系统减少动态效果设置。按空格可播放/暂停（焦点在按钮或表单时除外）。

## 文件

- `index.html`：网页结构。
- `style.css`：响应式样式。
- `animation.js`：连续丝线、归位和阶段过渡。
- `assets/artwork.png`：派生的纹样、线稿与色稿位图。
- `assets/routes.png`：采样后的运动数据。
- `assets/motifs.json`：位图位置、时间和布局。
- `assets/original-cloth.jpg`：压缩后的展示照片。

原始 AI、SVG、书页说明图及内部部署配置未提交。运行时运动数据由原图派生，可以用于重建展示用轮廓；它不是加密或 DRM。保持仓库私有，网页访客仍可获取浏览器加载的代码和展示素材。
