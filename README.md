# 纹归 · 一线成纹

50 秒逐线勾勒动画：从中央小段线开始，依次描出盘绕细纹，最终呈现用户提供的完整苗族蚕龙纹线稿。保留原稿中的独立轮廓，按临近笔画接续；不添加改变构图的永久连接线。

## 运行

在项目目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000 。无需安装依赖。

支持暂停、重播、时间轴回看、0.5× / 1× / 2×、全屏。优先使用 WebGL，提供 Canvas 2D 回退。

## 实现与素材

浏览器仅加载两张派生 PNG：像素描线时间图与线头位置图。原始 AI/SVG、矢量路径、书页说明图片均未上传。PNG 中保留的是展示所需的像素信息，访客仍可获取网页代码和这些位图；这不构成 DRM。

请保持仓库私有。`.gitignore` 排除 AI、SVG、PSD、内部配置与依赖目录。旧版本可从 Git commit 历史查看。
