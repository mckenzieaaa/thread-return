# 纹归 · Thread Return

20 秒网页动画：线稿苏醒、游动、归位，最后渐变为原布面照片。

## 运行

在项目目录运行 `python3 -m http.server 8000`，浏览器打开 http://localhost:8000 。无需安装依赖或构建。

支持暂停、重播、拖动时间轴、调速与全屏。

## 素材保护

只包含网页播放用的压缩 PNG/JPG；未包含 AI、PSD、原始 SVG、Sites 内部配置或任何凭据。请保持仓库为 Private。部署网页后，访客仍可获取浏览器加载的代码与位图。

四角纹样使用镜像复用，归位近似对齐，原始照片在结尾渐显。
